# study

Учебный проект на языке C с реализациями классических алгоритмов и функций стандартной библиотеки.

## Структура проекта

```
src/
├── math/           # Математические алгоритмы
│   ├── canonical.c         — каноническое разложение числа на простые множители
│   ├── count_del.c         — подсчёт количества делителей числа
│   ├── first_divider.c     — нахождение наименьшего делителя числа
│   ├── gcd.c               — наибольший общий делитель (итеративный и рекурсивный)
│   ├── is_prime.c          — проверка числа на простоту
│   ├── print_reverse_num.c — разворот цифр числа
│   ├── struc.c             — арифметические операции над структурами с полями double
│   └── structure.c         — структуры точки и отрезка, вычисление расстояний
└── string/         # Строковые функции
    ├── ctype.c             — собственные реализации функций <ctype.h>
    └── string.c            — собственные реализации функций <string.h>
```

## Модули

### math

| Файл | Функция(и) | Описание |
|------|-----------|----------|
| `canonical.c` | `canonical(n, size)` | Возвращает массив простых множителей числа `n` (каноническое разложение) |
| `count_del.c` | `count_del(n)` | Возвращает количество делителей числа `n` |
| `first_divider.c` | `first_divider(n)` | Возвращает наименьший делитель числа `n`, больший 1 |
| `gcd.c` | `gcd(a, b)`, `gcd_rec(a, b)` | НОД двух чисел: итеративный (алгоритм Евклида) и рекурсивный варианты |
| `is_prime.c` | `is_prime(num)` | Проверяет, является ли `num` простым числом |
| `print_reverse_num.c` | `return_reverse_num(n)` | Возвращает число, составленное из цифр `n` в обратном порядке |
| `struc.c` | `summation_two_double`, `subtraction_two_double`, `product_of_two_double` | Сложение, вычитание, умножение для пар вещественных чисел, упакованных в структуру |
| `structure.c` | `line_length`, `distance_between_two_points`, `distance_between_two_points_coord` | Длина отрезка и расстояние между двумя точками на плоскости |

### string

| Файл | Функция(и) | Описание |
|------|-----------|----------|
| `ctype.c` | `my_isalpha`, `my_isdigit`, `my_isblank`, `my_isalnum`, `my_islower`, `my_isupper`, `my_ispunct`, `my_iscntrl`, `my_isxdigit`, `my_isgraph`, `my_isprint`, `my_isspace` | Ручные реализации функций классификации символов из `<ctype.h>` |
| `string.c` | `my_strlen`, `my_strdup`, `my_strcmp`, `my_strstr`, `my_strcat`, `del_elem`, `copy_array`, `palindrom` | Ручные реализации строковых функций из `<string.h>`, а также удаление элемента из массива и проверка строки-палиндрома |

## Сборка и запуск

Каждый файл содержит раздел `#ifdef MAIN` с тестовым `main()`. Чтобы скомпилировать и запустить конкретный модуль, передайте флаг `-DMAIN`:

```bash
# Пример: проверка простоты числа
gcc -DMAIN -lm src/math/is_prime.c -o is_prime && ./is_prime

# Пример: строковые функции
gcc -DMAIN src/string/string.c -o string_test && ./string_test

# Пример: функции классификации символов
gcc -DMAIN src/string/ctype.c -o ctype_test && ./ctype_test
```

> Флаг `-lm` нужен для файлов, использующих `<math.h>` (большинство файлов в `src/math/`).

## Требования

- Компилятор C (GCC / Clang), поддерживающий стандарт C99 или новее
- Стандартная математическая библиотека (`libm`)
